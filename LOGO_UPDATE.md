# BLUEPRINT BUDDIES Logo Update

This update implements the approved BLUEPRINT BUDDIES logo system across the website.

## Included
- Horizontal logo lockup in desktop/mobile navigation
- Inverse lockup for dark mobile menu
- Inverse stacked logo in footer
- BB monogram as Next.js app icon / favicon
- Apple touch icon
- Responsive sizing for desktop, tablet, and mobile
